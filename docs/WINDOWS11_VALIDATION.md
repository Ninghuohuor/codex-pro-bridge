# Codex Pro Bridge：Windows 11 验证

## 已验证范围

- Windows 11 Pro、Node.js 24.16.0：TypeScript 类型检查和构建通过。
- 完整离线测试 74/74 通过，覆盖 Windows ACL、NTFS junction、MCP 多客户端、运行器退出与发送账本。
- 从本地安装包在独立临时目录中安装后，CLI 启动、环境检查、SQLite 完整性检查以及配置安装和卸载通过。
- GitHub Actions 的 Windows Server 2022 离线测试通过。

## 测试时序调整

运行器启动相关用例在高并发测试中出现过超时。将默认测试文件并发数限制为 2，并扩大运行器选举等待窗口后，默认测试通过。该结果仅覆盖已执行的离线路径。
